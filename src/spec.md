# Specification

## Summary
**Goal:** Improve the waitlist signup UX by handling errors and retry states cleanly.

**Planned changes:**
- Update the waitlist signup flow to display a clear inline error message when submission fails.
- Add a “Clear error and retry” action that resets the error state and allows the user to resubmit.

**User-visible outcome:** If the waitlist signup fails, users see an understandable error message and can clear it and try again without leaving the page.
